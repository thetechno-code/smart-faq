# User Manual

## 1. Login
Use the login page to enter your email and password.

## 2. Upload Error Screenshot
Open the Upload page, choose an image, and submit it.

## 3. Review OCR Output
The system shows parsed service, error code, and description.

## 4. Search FAQ
Use the FAQ page to search exact matches or semantic search results.

## 5. View History and Analytics
Open the History and Analytics pages to review previous searches and trends.
